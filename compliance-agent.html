Compliance Agent Monitoring

Two ways to work: let the agent watch and propose when signals change, or create a rule from scratch with a guided builder (manual or agent-assisted).

Autonomy
How much can the agent do on its own? Applies to this workspace · changeable anytime
Level 1
Suggest only
Surfaces ideas. Nothing changes until you act.
Level 2 · Current
Flag for review
Proposes specific rule changes and waits for your approval.
Level 3
Auto-apply low-risk
Applies safe changes automatically, notifies you, asks on big ones.
Level 4
Autonomous
Maintains rules end-to-end. Full audit trail; reversible.
Flag for review: the agent does the analysis and drafts the exact rule change, but every change needs your approval before it goes live.

Who does this rule apply to?

Rules attach to user groups — the same org structure admins already use in the shipped console.

Default or exception?

Exceptions override defaults when they match. Set priority order so admins know what wins.

Default context
Baseline rule for this user group. Lower priority than exceptions.
Exception context
Overrides default when conditions match. Use for department-specific policy.

What should happen in catalog search?

Display rules control sorting and hiding — separate surfaces in the shipped console.

Sorting rule
Rank preferred suppliers or compliance tiers higher in results.
Hiding rule
Remove options from search (e.g. off-contract punch-outs).
